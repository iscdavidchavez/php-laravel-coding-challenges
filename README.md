# PHP/Laravel Coding Challenges

Each problem has its own feature test

#### Installation
- clone repo ```git clone https://github.com/iscdavidchavez/php-laravel-coding-challenges```
- create .env file (just copy .env.example)
- run ```php artisan test```

### Problems
-  Dynamic Rule Engine (Policy-like System)
-  Nested Eloquent Search Filter
- State Machine for Models
